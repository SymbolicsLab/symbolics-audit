## 4. ★★ THE OBJECT RESTATED (PB) — a RELATA-CHAIN

L1 **distinctions** → L2 **combinations of distinctions = forms** → L3 **relations between forms** →
L4 **variations of relations** → L5+ **the stack, as mine**. Each rung is *one distinction*, taking as its
relatum **what the rung below produced**. **Kind = move + relatum-type** — the operation-kind is not
posited per rung; it is what the one move *becomes* on that relatum.

**What it does:**
- **Dissolves the three-formal-homes fork.** The Agda is right that there is one move and wrong that the
  kinds are mere readings; the vault is right that the kinds are real and would be wrong to treat them as
  four separate constitutive moves.
- **Relabels dive 5's three failures as FORMALIZATION defects** — L3's relata are *forms*, so a relation
  between forms is not definable between two L1 firings; the Agda built a relation without the type
  constraint.
- **★ Delivers the shape** the survey said a generator cannot (consolidated §7.3). Turing degrees, Powers
  and Kelsen run one operation on **one type** — hence negotiable counts. **A relata-chain bars
  interpolation and fixes the order.** New falsification test: *name a relatum-type between two of ours.*
- **★ Replaces the exhaustion terminus with a DERIVED one.** The last relatum is **total** (the taking is
  done by what is taken), so any further distinction is already inside it — a Kripke-fixed-point shape,
  which the survey listed among the *derived* termini, with Kriegel as a second precedent.

**⚠ RATIFICATION GATE.** The vault states levels as **operation-kinds**. Whether the relata-chain is a
*sharpening* or a *change* is a **fresh-vault-session** question, and everything in the study is
downstream of it.
